SECTION 01 — CORE ARCHITECTURE

다중 LLM 4역할 자율 협업 구조

단일 LLM의 환각·편향·논리적 오류를 구조적으로 상쇄하기 위해, 의도적 이해관계 대립에 기반한 4단계 고정 역할 분화를 채택합니다. 각 모듈에는 상이한 효용 함수(utility function)가 부여되어 프롬프트 수준이 아닌 알고리즘적 역할 분화를 실현합니다.

MODULE A
조력 LLM
사용자 이익 극대화. 증거 인출 엔진을 통해 Private Data Vault에서 무결성 검증된 데이터를 인출하여 논리적 근거로 활용.
MODULE B
방해 LLM
대립 이익 극대화. 결과물의 오류·미비점·논리적 허점을 구조화된 지적 사항으로 생성.
MODULE C
중재 LLM
합의 도출 엔진에 의한 쟁점 분해, 순차 합의, 양보 대칭성 감시, 합의 품질 평가.
MODULE D
승인 모듈
인간 주도 + LLM 보조. 최종 결정권은 인간에게 귀속되며 법적 책임소재가 명확.

A는 특정 개인 또는 기관의 이익을, B는 사회·국가 또는 대립 요소의 이익을 대변합니다. C와 D가 양측을 중재·조정하며, 이 구조는 현실 세계의 이해관계 대립 상황을 모사(simulation)하여 단일 관점의 편향을 상쇄합니다.

SECTION 02 — CONVERGENCE & CONSENSUS

정량적 수렴 판단 및 합의 도출

A와 B 간의 반복적 논쟁의 종결 시점을 코사인 유사도 기반 알고리즘이 객관적으로 결정합니다. 수렴 후에는 합의 도출 엔진이 쟁점별 순차 합의를 수행하여 단순 소진이 아닌 실질적 합의를 보장합니다.

수렴 판단 알고리즘

  1. 결과물 변동 점수(ΔR) — 연속 라운드의 결과물을 벡터 임베딩 후 코사인 유사도를 측정합니다. ΔR = 1 − cos(Ri, Ri-1)으로, 0에 가까울수록 변동 없음을 의미합니다.
  2. 신규 지적 점수(ΔC) — B의 지적 사항을 이전 누적 집합과 비교하여, 최대 유사도가 θn(0.85) 미만인 지적만 신규로 분류합니다.
  3. 수렴 판정 — 연속 W(기본 3)개 라운드에서 Avg(ΔR) ≤ θR 이고 Avg(ΔC) ≤ θC이면 수렴 상태로 판정합니다.

합의 도출 엔진

  1. 쟁점 분해 — 논쟁 대상을 독립적으로 합의 가능한 개별 쟁점(issue) 단위로 분해합니다.
  2. 쟁점별 순차 합의 — 각 쟁점에 대해 A·B가 집중 논쟁하고, 합의된 쟁점은 고정(lock)하여 재론을 방지합니다.
  3. 양보 추적 — 각 라운드에서 효용 함수 값 변화량을 양보율로 추적하고, 양보 대칭성이 임계값 미만이면 추가 논증을 요구합니다.
  4. 합의 품질 평가 — 양측 수용도(BAS), 양보 대칭성(CSI), 쟁점 해소율(IRR)의 가중 합으로 합의 품질 종합 점수(CQS)를 산출합니다.
CQS = w₁ · BAS + w₂ · CSI + w₃ · IRR

SECTION 03 — PRIVATE DATA VAULT

계층적 해시 분산 기반 데이터 금고

AI가 데이터의 진위를 판단하려면 데이터 자체의 무결성이 보장되어야 합니다. Private Data Vault는 원본 데이터의 이중 해시값(H′ = SHA-256(SHA-256(D) ∥ T))만을 계층적 DHT 네트워크에 분산 저장하여, 합의 메커니즘 없이 O(1) 무결성 검증을 실현합니다.

SECTION 05 — OPTIMIZATION & AUDIT

계산 효율화 및 의사결정 감사

다중 LLM의 반복적 상호작용에 따른 계산 비용을 40~60% 절감하면서 품질을 유지합니다. 모든 의사결정 과정은 해시 체인 기반 불변 로그로 기록됩니다.

메커니즘내용
병렬 처리복수 인스턴스(예: 3개)를 병렬 운영 후, 병합 모듈이 품질 점수(자기 확신도 0.3 + 맥락 일관성 0.4 + 완전성 0.3)로 평가. 코사인 유사도 기반 직접 선택(≥0.9) / 장점 융합(0.6~0.9) / 최적 선택(<0.6) 결정.
적응적 모델 선택초기 라운드(1~3)는 경량 모델(≤70B), 수렴 근접 시 고성능 모델(≥400B)로 전환하여 정밀도가 필요한 시점에만 고비용 리소스를 투입.
시맨틱 캐시이전 라운드 응답을 벡터 임베딩으로 저장. 유사 입력 감지 시 재활용하여 중복 연산 방지.
의사결정 감사 로그각 로그 항목의 해시가 이전 항목의 해시와 결합하여 해시 체인 형성. AI 권고, 쟁점별 양보 이력, 합의 품질 점수, 인간 검토 과정, 최종 결정 및 사유를 기록하여 책임소재 규명의 근거 제공.
