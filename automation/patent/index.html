지식재산처의 역할 전환

고팡 시스템에 의해, 지식재산처(특허청)는 출원자의 '심판관' 역할에서 출원자의 시간과 비용을 절약하고, 등록 가능성을 극대화하는 지적재산권 도우미로 전환합니다. 구체적으로, 지적재산권 취득 가능성이 낮은 아이디어는 조기에 걸러내어, 시민과 기업의 시간과 비용 손실을 막고, 혁신적 아이디어에 다수의 전문 에이전트를 지원하여, 출원서 작성의 전 과정을 보조함으로써, 출원 비용을 80~90% 줄일 뿐 아니라, 지재권 등록 가능성을 99%이상으로 높입니다. 무엇보다, 현재 수 년이 걸리는 출원서 준비, 심사 및 등록의 전 과정을 수 시간 안팎, 수백분의 일(1)로 줄입니다.

시스템 구성 요소

오픈소스 LLM을 기반으로 구축된 4가지 핵심 에이전트 시스템:

1. 전문 분야 변리사 & 평가 에이전트
업종, 산업, 기술 분야별로 Fine-tuning된 전문 분야 변리사 Agent와 전문 분야 평가 Agent를 생성합니다.
2. 지식재산처 전문 기관 에이전트
지식 재산처의 기능과 역할을 심판관에서 도우미로 전환한 전문 기관 Agent를 생성합니다.
3. AI 비서 에이전트
사용자(개인과 기업)의 Private Data Vault를 관리하고, 사용자의 요구를 수행할 외부 전문 기관 Agent를 선별 및 선택할 능력을 Fine-tuning한 "AI 비서 Agent"를 생성합니다.
4. Openhash 네트워크 에이전트
기록된 데이터의 위변조 가능성을 원천 차단하는 Openhash 네트워크를 운용하고, 갱신하며, 검증하는 Openhash Agent를 생성합니다.
Global Openhash Network
Global Openhash Network는 개인과 기업의 Private Data Vault를 비롯하여, 모든 기록의 진실성(True)를 보장하는 세계 최초, 세계 유일의 기술입니다. 블록체인 기반의 분산 원장 기술을 넘어선 차세대 데이터 무결성 보장 시스템으로, 모든 기록의 변경 이력을 실시간 추적하고 검증합니다.

AI 비서
(에이전트 조정자)
출원인의 개인 비서로서 지식재산처 Agent, 변리사 Agent와 평가 Agent를 호출하고 전체 프로세스를 조정합니다. 출원인의 이익을 대변하며, Private Data Vault의 기록을 활용한 맞춤형 서비스를 제공합니다.
변리사 Agent
(IT 분야 출원서 작성 전문가)

평가 Agent
(독립적 품질 검증자)
