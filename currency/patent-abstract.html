Overview

핵심 3대 기술

오픈해시 시스템은 계층 분산 무결성 검증, AI 기반 디지털 화폐, 자기주권 신원 인증이라는 3가지 핵심 기술의 융합으로 구성됩니다.

제1부: 계층 분산 데이터 무결성
기존 이동통신 네트워크의 5단계 행정 계층 구조(글로벌→국가→광역시도→시군구→읍면동)를 그대로 활용하여, 작업증명(PoW)이나 지분증명(PoS) 없이도 데이터 무결성을 확률적으로 보장합니다. 계층별 잔액 불변성 검증과 5단계 거래 검증 파이프라인으로 기존 블록체인 대비 에너지를 98.5% 절감합니다.
제2부: AI 디지털 화폐 시스템 (EGCT)
민간 기업이 자유롭게 디지털 화폐를 발행·운용할 수 있는 플랫폼입니다. BERT-CNN-LSTM 앙상블 AI가 99.4% 정확도로 부정거래를 탐지하고, FPGA 칩이 암호 연산을 0.032ms에 처리합니다. 거래 즉시 재무제표가 자동 생성되고, 자율 은행·보험·증권 서비스가 통합 제공됩니다.
SSI 자기주권 신원 인증
중앙 인증 기관 없이, 사용자가 직접 5가지 요소(신분증 원본, 발행자 서명, 해시값, 계층·노드 정보, 저장 시각)를 제시하여 신원을 증명합니다. 개인정보 주권을 사용자에게 완전히 돌려주며, 필요한 정보만 선택적으로 공개할 수 있습니다.
How It Works

거래가 처리되는 과정

하나의 거래가 발생하면, 오픈해시 시스템은 다음과 같은 단계로 처리합니다.

1

거래 발생 → 최하위 계층 노드가 수신

사용자가 디지털 화폐 거래를 시작하면, 가장 가까운 읍면동 단위 노드가 이를 수신합니다. 기존 이동통신 인프라를 활용하므로 별도 네트워크가 필요 없습니다.

인프라 투자 비용: 0원
2

5단계 거래 검증 파이프라인

거래는 구문 검증 → 잔액 확인 → 이중지불 방지 → 서명 검증 → 비즈니스 규칙 검증까지 총 5단계를 거칩니다. 이 과정에서 계층별 잔액 불변성도 함께 검증됩니다.

계층 간 검증 시간: 4ms
3

AI 앙상블 검증 + FPGA 가속 영지식 증명

BERT-CNN-LSTM 앙상블 모델이 부정거래를 탐지(99.4% 정확도)하고, FPGA가 BN254 타원곡선 병렬 페어링으로 영지식 증명을 0.032ms에 완료합니다.

FPGA 검증: 0.032ms · AI 탐지: 99.4%
4

재무제표 자동 생성 + 자율 금융 서비스

검증 완료 즉시, 재무상태표·손익계산서·현금흐름표가 자동으로 생성됩니다. AI가 이 데이터를 실시간 분석하여 자율 은행(대출), 자율 보험(보장), 자율 증권(투자) 서비스를 최적화합니다.

전체 처리 시간: 0.87ms
5

크로스체인 연동 + 글로벌 규제 자동 준수

이더리움·폴리곤·아비트럼·zkSync 등 기존 블록체인과 원자적 자산 이동이 가능하며, 30개국 규제 프레임워크를 24시간 자동으로 준수합니다.

호환 체인: 4종 · 규제 커버리지: 30개국
Comparison

기존 블록체인 vs 오픈해시

기존 블록체인 기술의 근본적 한계를 새로운 패러다임으로 해결합니다.

⚠️ 기존 블록체인 (PoW/PoS)

  • 막대한 전력 소비 (비트코인: 연간 150TWh)
  • 느린 거래 처리 (10분~수 시간 소요)
  • 높은 인프라 구축 비용 (전용 네트워크 필요)
  • 낮은 부정거래 탐지율 (85~90%)
  • 중앙 인증 기관 의존 (단일 실패점 존재)
  • 개인정보 유출 위험 (원본 데이터 중앙 보관)
  • 제한된 확장성과 크로스체인 호환성
VS

✅ 오픈해시 디지털 화폐 시스템

  • 에너지 98.5% 절감 (기존 통신망 활용)
  • 0.032ms 거래 검증, 4ms 계층 간 검증
  • 별도 인프라 불필요 (유지보수 80~90% 절감)
  • AI 앙상블 99.4% 부정거래 탐지율
  • SSI 기반 탈중앙 인증 (단일 실패점 없음)
  • 해시값만 저장 — 원본은 사용자가 보유
  • 4개 블록체인 원자적 연동 + 30개국 규제 준수
