확률적 계층 선택 + 가장 가까운 노드
사용자는 선택된 계층에서 자신과 가장 가까운 노드에 해시 전송
사용자 → 노드 (해시 전송)
노드 → 사용자 (최종 해시 반환)
Layer 1: 80% Layer 2: 15% Layer 3: 4% Layer 4: 1%
📌 메시지 1/9
사용자는 거래 데이터를 자신의 PDV(Private Data Vault)에 저장하고, Hash를 추출.
사용자가 다음 위치로 이동 중...
사용자가 좌우로 이동하며, 각 위치에서 확률에 따라 계층을 선택한 후 가장 가까운 노드에 해시를 전송(파란 점)하고 반환(빨간 점)받습니다.
메시지는 5초마다 자동으로 넘어갑니다.
