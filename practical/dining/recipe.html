대화 예시

1레시피 추천

사용자: 오늘 저녁 뭐 해먹을까? 냉장고에 있는 거로.

사용자_AI: (Vault 냉장고재고/요리실력 인출) 레시피_AI에 추천 요청.

레시피_AI: 냉장고 재고 기반 레시피 추천.

🧊 현재 재고
• 돼지고기, 양파, 대파, 마늘
• 고추장, 간장, 설탕
• 밥

👨‍🍳 추천 레시피

1️⃣ 제육볶음 ⭐바로 가능
• 난이도: ★★☆

2️⃣ 돼지불백 ⭐바로 가능
• 난이도: ★☆☆

3️⃣ 돈까스 🛒빵가루 필요

• 조리시간: 30분

어떤 요리 할까요?

사용자_AI: 레시피 추천 Vault '식사-레시피추천'에 저장. Hash → OpenHash L1 서귀포시 노드 저장.

2단계별 요리 가이드

사용자: 제육볶음 만들어볼게. 알려줘.

사용자_AI: 레시피_AI에 요리 가이드 요청.

레시피_AI: 제육볶음 레시피 시작합니다.

📝 재료 (2인분)
• 돼지고기 앞다리 300g
• 양파 1/2개, 대파 1대
• 고추장 2T, 간장 1T
• 설탕 1T, 다진마늘 1T

👨‍🍳 Step 1: 재료 준비
• 고기는 한입 크기로 썰기
• 양파는 채썰기, 대파는 어슷썰기

준비되면 "다음"이라고 해주세요.

사용자: 다음

레시피_AI: 👨‍🍳 Step 2: 양념장 만들기
• 볼에 고추장 2T + 간장 1T
• 설탕 1T + 다진마늘 1T
• 참기름 1t + 후추 약간
• 잘 섞어주세요

준비되면 "다음"!

사용자: 다음

레시피_AI: 👨‍🍳 Step 3: 볶기
• 팬에 기름 두르고 센불
• 고기 먼저 2분 볶기
• 양념장 넣고 2분 더 볶기
• 양파, 대파 넣고 1분 볶기

🍳 완성! 맛있게 드세요!

사용자_AI: 요리 완료 Vault '식사-요리기록'에 저장. Hash → OpenHash L1 서귀포시 노드 저장.

3재료 장보기

레시피_AI: 주간 저녁 식단 및 장보기 목록.

• 수: 김치찌개 + 계란말이
• 목: 불고기 + 미역국
• 금: 파스타

🛒 장보기 목록

마트_AI에 주문 요청할까요?
