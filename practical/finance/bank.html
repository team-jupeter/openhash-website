대화 예시

1비대면 계좌 개설

사용자: 급여통장 만들어줘. 우리은행으로.

사용자_AI: (Vault 신분증/재직증명서 인출) 은행_AI에 계좌 개설 요청.

은행_AI: 우리은행 급여통장 개설 완료. 계좌번호 1002-xxx-xxxxxx. 체크카드 발급 신청됨. 회사에 급여계좌 등록 필요.

사용자_AI: Vault '금융-계좌'에 저장(암호화). Hash → OpenHash L1 제주시 노드 저장.

2신용대출 신청

사용자: 3천만원 신용대출 받고 싶어. 금리 제일 낮은 곳으로.

사용자_AI: (Vault 소득증빙/신용정보 인출) 은행_AI에 대출 비교/신청.

은행_AI: 5개 은행 금리 비교 완료. 최저: 신한은행 4.2%. 대출신청서 작성/제출 완료. 한도 3,500만원 승인. 실행일 선택 필요.

(사용자 승인: 내일 실행)

사용자_AI: 대출 실행 예약. Vault '금융-대출'에 기록. Hash → OpenHash L2 제주시 노드 저장.

3자동이체 설정

사용자: 매달 25일에 월세 85만원 자동이체 설정해줘.

사용자_AI: (Vault 계좌정보/임대인계좌 인출) 은행_AI에 자동이체 설정.

은행_AI: 자동이체 설정 완료. 출금계좌: 국민 xxx-xxxx, 입금: 홍길동 신한 xxx-xxxx, 매월 25일 85만원. 잔액부족 시 알림 설정됨.

사용자_AI: Vault '금융-자동이체'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

4정기적금 가입

사용자: 매달 50만원씩 1년 적금 들어줘. 금리 높은 걸로.

사용자_AI: (Vault 계좌정보 인출) 은행_AI에 적금 비교/가입.

은행_AI: 적금 상품 비교 완료. 최고: 케이뱅크 연 4.5%(우대 포함). 정기적금 가입 완료. 만기 2027.1.27, 예상 만기금액 618만원.

사용자_AI: Vault '금융-적금'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5해외송금

사용자: 미국에 있는 아들한테 2천 달러 보내줘.

사용자_AI: (Vault 수취인정보/SWIFT코드 인출) 은행_AI에 해외송금 요청.

은행_AI: 해외송금 신청 완료. 금액: USD 2,000, 환율 1,320원, 원화 264만원+수수료 1.5만원 출금. 도착예정 1~2영업일.

사용자_AI: Vault '금융-해외송금'에 기록. Hash → OpenHash L2 제주시 노드 저장.
