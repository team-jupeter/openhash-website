대화 예시

1증권계좌 개설

사용자: 주식 시작하려고. 키움증권 계좌 만들어줘.

사용자_AI: (Vault 신분증/은행계좌 인출) 증권사_AI에 계좌 개설 요청.

증권사_AI: 키움증권 종합계좌 개설 완료. 계좌번호 8xxx-xxxx. 연결계좌: 국민 xxx-xxxx. 영웅문S 앱 설치 안내됨.

사용자_AI: Vault '금융-증권계좌'에 저장(암호화). Hash → OpenHash L1 제주시 노드 저장.

2주식 매수 주문

사용자: 삼성전자 10주 사줘.

사용자_AI: (Vault 증권계좌/예수금 확인) 증권사_AI에 매수 주문.

증권사_AI: 삼성전자(005930) 매수주문 완료. 수량 10주, 현재가 71,500원, 총 715,000원. 체결 대기 중. 체결 시 알림 예정.

사용자_AI: Vault '투자-주문내역'에 기록. Hash → OpenHash L1 제주시 노드 저장.

3펀드 가입

사용자: 매달 30만원씩 S&P500 펀드 적립식으로 가입해줘.

사용자_AI: (Vault 투자성향/계좌정보 인출) 증권사_AI에 펀드 가입.

증권사_AI: 미래에셋 TIGER S&P500 ETF 적립식 가입 완료. 매월 1일 30만원 자동매수. 총보수 0.07%. 첫 매수일 2/1.

사용자_AI: Vault '투자-펀드'에 기록. Hash → OpenHash L1 제주시 노드 저장.

4연금저축 납입

사용자: 연금저축 올해 세액공제 한도까지 채워줘.

사용자_AI: (Vault 연금계좌/납입내역 인출) 증권사_AI에 연금저축 납입.

증권사_AI: 연금저축 추가납입 완료. 기납입 300만원 → 추가 300만원 = 연간 600만원 한도 충족. 예상 세액공제 99만원(16.5%).

사용자_AI: Vault '연금-저축'에 기록. Hash → OpenHash L2 제주시 노드 저장.

5해외주식 매수

사용자: 애플 5주 사줘. 환전도 해줘.

사용자_AI: (Vault 해외주식계좌/예수금 인출) 증권사_AI에 환전 및 매수 주문.

증권사_AI: 원화 환전 완료: 1,200,000원 → USD 909. 애플(AAPL) 매수주문 5주 × $178 = $890. 미국장 개장 시(23:30) 체결 예정.

사용자_AI: Vault '투자-해외주식'에 기록. Hash → OpenHash L2 제주시 노드 저장.
