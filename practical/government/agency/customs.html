대화 예시

1해외직구 관세 납부

사용자: 미국에서 주문한 노트북 통관 상태 확인하고 관세 납부해줘.

사용자_AI: (Vault 주문정보 확인) 관세청_AI에 통관 조회 요청.

관세청_AI: 물품 도착. 과세가격 $1,200, 관세+부가세 182,000원. 납부하시겠습니까?

(사용자 승인)

관세청_AI: 납부 완료. 통관 승인됨. 배송 시작.

사용자_AI: Vault '통관-직구'에 기록. Hash → OpenHash L2 인천시 노드 저장.

2여행자 휴대품 신고

사용자: 내일 일본 여행 귀국하는데 면세한도 초과분 미리 신고해줘.

사용자_AI: (Vault 여권/여행정보 인출) 관세청_AI에 사전신고 요청.

관세청_AI: 면세한도 $800 초과분 $450. 예상 세금 54,000원. 사전납부하시겠습니까?

(사용자 승인)

관세청_AI: 사전신고 완료. 입국 시 자동 통관 처리됨.

사용자_AI: Vault '통관-여행'에 기록. Hash → OpenHash L1 제주공항 노드 저장.

3수입신고 처리

사용자: 중국에서 들어오는 원자재 수입신고 해줘.

사용자_AI: (Vault 사업자/수입계약 인출) 관세청_AI에 수입신고 요청.

관세청_AI: HS코드 확인. 관세율 8%, 관세 4,800,000원. 신고 및 납부하시겠습니까?

(사용자 승인)

관세청_AI: 수입신고 수리 완료(신고번호: IMP-2026-01234).

사용자_AI: Vault '무역-수입'에 기록. Hash → OpenHash L3 대한민국 노드 저장.

4FTA 원산지 증명

사용자: EU로 수출하는데 FTA 원산지증명서 발급해줘.

사용자_AI: (Vault 수출계약/제품정보 인출) 관세청_AI에 증명서 발급 요청.

관세청_AI: 한-EU FTA 원산지 충족 확인. 원산지증명서 발급 완료.

사용자_AI: 바이어_AI에 증명서 전송. Vault '무역-원산지'에 기록. Hash → OpenHash L2 부산시 노드 저장.

5관세 환급 신청

사용자_AI: Vault '무역-환급'에 기록. Hash → OpenHash L2 서울시 노드 저장.
