대화 예시

1해양 조난 신고

사용자: 배가 고장났어! 표류 중이야! 구조 요청해줘!

사용자_AI: (Vault GPS 위치 즉시 인출) 해양경찰청_AI 긴급 호출.

해양경찰청_AI: 122 구조 출동. 현위치 북위 33.2도, 동경 126.5도. 해경 경비함 15분 내 도착. 구명조끼 착용 유지.

사용자_AI: Hash → OpenHash L4 대한민국 노드 저장(긴급).

2선박 출항 신고

사용자: 내일 아침 낚시배 출항 신고해줘.

사용자_AI: (Vault 선박정보/승선자명단 인출) 해양경찰청_AI에 출항신고.

해양경찰청_AI: 출항신고 완료. 출항: 2/1 05:00 서귀포항, 귀항 예정: 18:00, 승선 4인. 기상 이상 시 자동 알림.

사용자_AI: Vault '해양-출항'에 기록. Hash → OpenHash L1 서귀포항 노드 저장.

3해양오염 신고

사용자: 바다에 기름 띠가 보여. 신고해줘.

사용자_AI: (Vault 위치/사진 인출) 해양경찰청_AI에 오염신고.

해양경찰청_AI: 해양오염 신고 접수. 방제팀 출동 중. 도착 예정 25분. 추가 확산 시 재신고 요망.

사용자_AI: Vault '신고-해양오염'에 기록. Hash → OpenHash L2 제주도 노드 저장.

4수상레저 안전교육

사용자: 수상레저 조종면허 따려고 하는데 교육 신청해줘.

사용자_AI: (Vault 개인정보 인출) 해양경찰청_AI에 교육 신청.

해양경찰청_AI: 수상레저 안전교육 신청 완료. 2/15-16(2일), 제주해양경찰서. 비용 50,000원 결제됨.

사용자_AI: Vault '교육-수상레저'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5표류물 신고

사용자: 해변에 이상한 물체가 떠밀려왔어. 신고해야 할 것 같아.

사용자_AI: (Vault 위치/사진 인출) 해양경찰청_AI에 표류물 신고.

해양경찰청_AI: 표류물 신고 접수. 담당자 현장 확인 예정(30분 내). 접근 금지 유지 요망.

사용자_AI: Vault '신고-표류물'에 기록. Hash → OpenHash L1 중문해변 노드 저장.
