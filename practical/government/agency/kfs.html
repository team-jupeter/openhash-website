대화 예시

1산불 신고

사용자: 한라산 쪽에서 연기가 보여! 산불인 것 같아!

사용자_AI: (Vault 위치정보 즉시 인출) 산림청_AI 긴급 호출.

산림청_AI: 산불 신고 접수. 산불진화헬기 출동. 소방청_AI 연동 완료. 현재 위치에서 대피하세요.

사용자_AI: Hash → OpenHash L3 제주도 노드 저장(긴급).

2등산로 예약

사용자: 이번 주말 한라산 성판악 코스 예약해줘.

사용자_AI: (Vault 개인정보 인출) 산림청_AI에 예약 요청.

산림청_AI: 성판악-백록담 코스 예약 완료. 2/1 05:00 입산, 4인. 기상 주의보 없음.

사용자_AI: Vault '여가-등산'에 기록. Hash → OpenHash L1 제주시 노드 저장.

3벌채허가 신청

사용자: 우리 땅 소나무 벌채허가 신청해줘.

사용자_AI: (Vault 토지정보/산림조사서 인출) 산림청_AI에 허가 신청.

산림청_AI: 벌채허가 심사 접수. 현장조사 2/15 예정. 심사기간 약 14일.

사용자_AI: Vault '산림-벌채'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

4산림 내 시설 설치 허가

사용자: 임야에 전원주택 짓고 싶어. 허가 신청해줘.

사용자_AI: (Vault 토지/건축계획 인출) 산림청_AI에 허가 신청.

산림청_AI: 산지전용허가 심사 접수. 복구비 예치금 500만원 필요. 심사기간 약 30일.

사용자_AI: Vault '부동산-산지전용'에 기록. Hash → OpenHash L2 제주시 노드 저장.

5묘목 분양 신청

사용자: 조림용 묘목 분양 신청해줘. 편백나무 500주.

사용자_AI: (Vault 산림소유정보 인출) 산림청_AI에 분양 신청.

산림청_AI: 편백나무 500주 분양 승인. 주당 500원, 총 250,000원. 3월 중 배송 예정.

사용자_AI: Vault '산림-조림'에 기록. Hash → OpenHash L1 한경면 노드 저장.
