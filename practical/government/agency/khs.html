대화 예시

1궁궐 특별관람 예약

사용자: 경복궁 야간 특별관람 예약해줘.

사용자_AI: (Vault 개인정보 인출) 국가유산청_AI에 예약 요청.

국가유산청_AI: 경복궁 야간관람 예약 완료. 2/14 19:00, 2인. 입장료 6,000원 결제됨.

사용자_AI: Vault '여가-관람'에 기록. Hash → OpenHash L1 종로구 노드 저장.

2매장문화재 신고

사용자: 공사 중 유물 발견했어. 신고해줘.

사용자_AI: (Vault 위치/공사정보 인출) 국가유산청_AI에 신고.

국가유산청_AI: 매장문화재 신고 접수 완료. 현장 보존 조치 필요. 조사관 금일 16시 도착 예정.

사용자_AI: Vault '신고-문화재'에 기록. Hash → OpenHash L2 제주시 노드 저장.

3문화재 수리 지원

사용자: 우리 마을 정자가 등록문화재인데 수리 지원 신청해줘.

사용자_AI: (Vault 문화재등록정보/사진 인출) 국가유산청_AI에 지원 신청.

국가유산청_AI: 수리지원 심사 접수 완료. 예상 지원금 70%(최대 5천만원). 현장조사 2/25 예정.

사용자_AI: Vault '문화재-수리'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

4발굴조사 허가

사용자_AI: (Vault 연구계획/기관정보 인출) 국가유산청_AI에 허가 신청.

5문화재 국외반출 허가

사용자_AI: Vault '문화재-반출'에 기록. Hash → OpenHash L4 대한민국 노드 저장.
