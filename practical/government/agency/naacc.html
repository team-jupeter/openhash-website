대화 예시

1세종시 아파트 분양 신청

사용자: 세종시 신규 아파트 분양 신청해줘.

사용자_AI: (Vault 주택청약/소득정보 인출) 행복청_AI에 분양 신청.

행복청_AI: 6-4생활권 분양 신청 완료. 청약자격: 1순위(무주택 3년). 당첨발표 3/15.

사용자_AI: Vault '부동산-분양'에 기록. Hash → OpenHash L2 세종시 노드 저장.

2이전기관 종사자 주거지원

사용자: 세종으로 발령받았는데 공공임대 신청 가능할까?

사용자_AI: (Vault 재직증명/발령정보 인출) 행복청_AI에 임대 신청.

행복청_AI: 이전기관 종사자 우선 공급 대상 확인. 행복주택 신청 완료. 입주가능일 4/1.

사용자_AI: Vault '주거-임대'에 기록. Hash → OpenHash L1 세종시 노드 저장.

3상업용지 분양 조회

사용자: 세종시에 카페 창업하려고 하는데 상업용지 있어?

사용자_AI: (Vault 사업계획 확인) 행복청_AI에 용지 조회.

행복청_AI: 2-4생활권 근린상업용지 분양 중. 평당 850만원, 최소 50평. 신청 가능.

사용자_AI: Vault '사업-용지'에 기록. Hash → OpenHash L2 세종시 노드 저장.

4도시개발 민원

사용자: 우리 동네 앞 도로 공사 언제 끝나는지 알려줘.

사용자_AI: (Vault 주소정보 인출) 행복청_AI에 공사일정 조회.

행복청_AI: 3-1생활권 도로확장공사. 완료예정: 2026년 5월. 야간공사 민원은 별도 접수 가능.

사용자_AI: Vault '민원-도시개발'에 기록. Hash → OpenHash L1 세종시 노드 저장.
