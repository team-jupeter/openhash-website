대화 예시

1교통범칙금 납부

사용자: 지난주 속도위반 범칙금 확인하고 납부해줘.

사용자_AI: (Vault 차량정보 확인) 경찰청_AI에 범칙금 조회 요청.

경찰청_AI: 1건 확인. 속도위반(20km/h 초과) 범칙금 60,000원. 납부하시겠습니까?

(사용자 승인)

경찰청_AI: 납부 완료. 납부확인서 발급됨.

사용자_AI: Vault '교통-범칙금'에 기록. Hash → OpenHash L1 역삼동 노드 저장.

2분실물 신고

사용자: 어제 지하철에서 지갑 잃어버렸어. 분실 신고해줘.

사용자_AI: (Vault 개인정보 인출) 경찰청_AI에 분실신고 요청.

경찰청_AI: 분실신고 접수 완료(접수번호: LOST-2026-0127). 습득 시 자동 알림 설정됨.

사용자_AI: Vault '분실물-신고'에 기록. Hash → OpenHash L2 서울시 노드 저장.

3운전면허 갱신

사용자: 운전면허 갱신 기간인지 확인하고 갱신 신청해줘.

사용자_AI: (Vault 면허정보 확인) 경찰청_AI에 조회 요청.

경찰청_AI: 면허 만료 30일 전. 갱신 가능. 적성검사 예약 및 수수료 7,500원 결제하시겠습니까?

(사용자 승인)

경찰청_AI: 적성검사 예약 완료(2/3 오전 10시). 수수료 결제됨.

사용자_AI: Vault '교통-면허'에 기록. Hash → OpenHash L1 강남구 노드 저장.

4112 신고 접수

사용자: 앞집에서 큰 소리가 계속 나. 신고해줘.

경찰청_AI: 112 신고 접수 완료. 서귀포경찰서 순찰차 배치됨. 예상 도착 8분.

사용자_AI: Vault '신고-112'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

5신원조회서 발급
