대화 예시

1전자소송 사건 조회

사용자: 내 민사소송 진행 상황 확인해줘.

사용자_AI: (Vault 전자소송 인증정보 확인) 법원_AI에 사건 조회 요청.

법원_AI: 2026가단12345 손해배상 사건. 현재 변론기일 지정(2/20 14:00, 제주지방법원 302호). 준비서면 제출기한 2/15.

사용자_AI: Vault '법률-소송진행'에 기록. Hash → OpenHash L2 제주시 노드 저장.

2판결문 등본 발급

사용자: 작년 끝난 소송 판결문 등본 발급해줘.

사용자_AI: (Vault 사건번호 확인) 법원_AI에 판결문 발급 요청.

법원_AI: 2025가단54321 판결문 등본 발급 완료. 확정일 2025.11.20. 수수료 1,000원 결제됨.

사용자_AI: Vault '법률-판결문'에 저장. Hash → OpenHash L2 제주시 노드 저장.

3인지대 납부 (승인 필요)

사용자: 항소장 제출하려는데 인지대 납부해줘.

사용자_AI: (Vault 사건정보/결제정보 인출) 법원_AI에 인지대 납부 요청.

법원_AI: 소가 5,000만원, 인지액 450,000원. 납부하시겠습니까?

(사용자 승인)

법원_AI: 납부 완료. 납부확인서 발급됨.

사용자_AI: Vault '법률-소송비용'에 기록. Hash → OpenHash L3 제주도 노드 저장.

4등기부등본 발급

사용자: 이 부동산 등기부등본 발급해줘.

사용자_AI: (Vault 부동산 주소 인출) 법원_AI에 등기부등본 발급 요청.

법원_AI: 등기사항전부증명서 발급 완료. 제주시 연동 123-4. 갑구(소유권), 을구(근저당권 1건). 수수료 700원.

사용자_AI: Vault '부동산-등기'에 저장. Hash → OpenHash L1 연동 노드 저장.
