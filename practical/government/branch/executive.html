대화 예시

1국민제안 제출

사용자: 제주 관광객 쓰레기 문제 해결 방안 제안하고 싶어.

사용자_AI: (Vault 신분정보/제안내용 인출) 국정_AI에 국민제안 제출.

국정_AI: 국민제안 접수 완료(제안번호: PS-2026-12345). 관계부처: 환경부, 제주도. 검토 후 30일 내 답변 예정.

사용자_AI: Vault '정치-국민제안'에 기록. Hash → OpenHash L2 세종시 노드 저장.

2국무회의 안건 조회

사용자: 이번 주 국무회의에서 뭘 심의하는지 알려줘.

사용자_AI: (조회 요청) 국정_AI에 국무회의 안건 조회.

국정_AI: 제52회 국무회의 안건(1/28): 1.2026년 추경안, 2.디지털플랫폼정부법 시행령, 3.한-UAE 투자협정 비준안. 회의록 공개 예정일 2/4.

사용자_AI: Vault '정치-국무회의'에 기록. Hash → OpenHash L1 세종시 노드 저장.

3정부정책 브리핑 구독

사용자: 중소기업 관련 정책 발표되면 알려줘.

사용자_AI: (Vault 관심분야 설정) 국정_AI에 브리핑 구독 설정.

국정_AI: 정책브리핑 구독 설정 완료. 키워드: 중소기업, 소상공인, 창업. 관계부처(중기부/금융위) 보도자료 발표 시 즉시 알림.

사용자_AI: Vault '알림-정책브리핑'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

4규제혁신 건의

사용자: 드론 배송 규제가 너무 까다로워. 규제 완화 건의할게.

사용자_AI: (Vault 사업자정보/건의내용 인출) 국정_AI에 규제혁신 건의.

국정_AI: 규제혁신 건의 접수 완료. 규제개혁위원회 검토 안건 등재. 관계부처: 국토부, 과기정통부. 처리기한 60일.

사용자_AI: Vault '정책-규제혁신'에 기록. Hash → OpenHash L3 대한민국 노드 저장.

5정부포상 추천 확인

사용자: 회사에서 나를 정부포상 추천했다는데 진행 상황 확인해줘.

사용자_AI: (Vault 신분정보 인출) 국정_AI에 포상 진행 조회.

국정_AI: 정부포상 추천 확인됨. 추천훈격: 산업포장, 추천부처: 중기부. 현재 상훈심사 진행 중. 수여 예정: 3.1절 정부포상.

사용자_AI: Vault '포상-정부포상'에 기록. Hash → OpenHash L2 세종시 노드 저장.
