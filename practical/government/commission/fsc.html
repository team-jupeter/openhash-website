대화 예시

1핀테크 규제샌드박스 신청

사용자: 우리 스타트업 블록체인 결제 서비스 규제샌드박스 신청해줘.

사용자_AI: (Vault 사업계획서/기술문서 인출) 금융위_AI에 샌드박스 신청.

금융위_AI: 혁신금융서비스 지정 신청 접수 완료. 심사기간 약 60일. 금융규제 특례 적용 가능.

사용자_AI: Vault '사업-핀테크'에 기록. Hash → OpenHash L3 대한민국 노드 저장.

2불법사금융 신고

사용자: 연이율 200% 대출 권유받았어. 불법 사금융 신고해줘.

사용자_AI: (통화기록/문자 인출) 금융위_AI에 불법금융 신고.

금융위_AI: 불법사금융 신고 접수 완료. 경찰청_AI 수사 연계. 피해자 법률구조 지원 가능.

사용자_AI: Vault '금융-불법신고'에 기록. Hash → OpenHash L2 서울시 노드 저장.

3금융분쟁 조정 신청

사용자: 보험사가 보험금 지급을 거부해. 분쟁조정 신청해줘.

사용자_AI: (Vault 보험계약/진료기록 인출) 금융위_AI에 분쟁조정 신청.

금융위_AI: 금융분쟁조정 신청 접수 완료. 금감원_AI 조정위원회 배정. 조정기간 약 60일.

사용자_AI: Vault '금융-분쟁조정'에 기록. Hash → OpenHash L2 제주시 노드 저장.

4서민금융 지원 연계

사용자: 신용등급 낮아서 대출이 안 돼. 서민금융 상품 있을까?

사용자_AI: (Vault 소득/신용정보 인출) 금융위_AI에 서민금융 조회.

금융위_AI: 햇살론유스 자격 충족. 연 3.5%, 최대 1,200만원. 신청서 자동 작성 완료.

사용자_AI: 서민금융진흥원_AI에 신청 연동. Vault '금융-서민대출'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

5가상자산사업자 등록 조회

사용자: 이 코인거래소 정식 등록된 곳인지 확인해줘.

사용자_AI: (거래소명 입력) 금융위_AI에 등록 조회.

금융위_AI: 가상자산사업자 등록 확인. 등록번호: VASP-2024-0015. 금융정보분석원 신고 완료 업체.

사용자_AI: Vault '금융-가상자산'에 기록. Hash → OpenHash L1 강남구 노드 저장.
