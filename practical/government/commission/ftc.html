대화 예시

1하도급 대금 지연 신고

사용자: 원청업체가 3개월째 하도급 대금을 안 줘. 신고해줘.

사용자_AI: (Vault 계약서/세금계산서 인출) 공정위_AI에 신고 접수.

공정위_AI: 하도급법 위반 신고 접수 완료(신고번호: SUB-2026-1234). 조사 착수. 지연이자 14.5% 청구 가능.

사용자_AI: Vault '사업-하도급분쟁'에 기록. Hash → OpenHash L2 서울시 노드 저장.

2가맹본부 불공정행위 신고

사용자: 본사가 강제로 물품 구매하라고 해. 이거 불법 아니야?

사용자_AI: (Vault 가맹계약서 인출) 공정위_AI에 조회 및 신고.

공정위_AI: 가맹사업법 위반 소지 확인. 끼워팔기 강요 신고 접수 완료. 분쟁조정 신청도 병행 가능.

사용자_AI: Vault '사업-가맹분쟁'에 기록. Hash → OpenHash L2 대전시 노드 저장.

3담합 제보

사용자: 우리 업계 대형사들이 가격 담합하는 것 같아. 익명 제보 가능해?

사용자_AI: (익명처리 모드) 공정위_AI에 담합 제보.

공정위_AI: 카르텔 제보 접수 완료. 익명 보장됨. 자진신고 시 과징금 감면(리니언시) 안내 가능.

사용자_AI: Hash → OpenHash L4 대한민국 노드 저장(익명보장).

4소비자 피해구제 신청

사용자: 헬스장이 갑자기 폐업했는데 환불 안 해줘. 피해구제 신청해줘.

사용자_AI: (Vault 계약서/결제내역 인출) 공정위_AI에 피해구제 신청.

공정위_AI: 소비자 피해구제 접수 완료. 소비자원_AI 연계 조정 진행. 집단분쟁 대상 확인 중.

사용자_AI: Vault '소비자-피해구제'에 기록. Hash → OpenHash L2 제주시 노드 저장.

5대기업 갑질 신고

사용자: 납품단가 일방적으로 인하하라고 통보받았어. 신고할게.

사용자_AI: (Vault 거래내역/통보문서 인출) 공정위_AI에 불공정거래 신고.

공정위_AI: 대규모유통업법 위반 신고 접수 완료. 서면조사 후 현장조사 예정. 보복행위 시 가중처벌.

사용자_AI: Vault '사업-불공정거래'에 기록. Hash → OpenHash L3 대한민국 노드 저장.
