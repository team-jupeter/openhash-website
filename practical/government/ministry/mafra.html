대화 예시

1공익직불금 신청

사용자: 올해 공익직불금 신청해줘.

사용자_AI: (Vault 농업경영체정보/경작면적 인출) 농식품부_AI에 직불금 신청.

농식품부_AI: 기본형 공익직불금 신청 완료. 경작면적 1.5ha, 예상 수령액 연 205만원. 11월 지급 예정.

사용자_AI: Vault '농업-직불금'에 기록. Hash → OpenHash L1 한림읍 노드 저장.

2축산업 허가 신청

사용자: 흑돼지 사육 시작하려는데 축산업 허가 신청해줘.

사용자_AI: (Vault 토지/시설정보 인출) 농식품부_AI에 허가 신청.

농식품부_AI: 축산업 허가 신청 접수 완료. 사육시설 검사 일정: 2/15. 환경영향평가 필요 여부 확인 중. 심사기간 약 30일.

사용자_AI: Vault '축산-허가'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

3농업재해보험 가입

사용자: 감귤 농사 태풍 피해 대비해서 재해보험 가입해줘.

사용자_AI: (Vault 농업경영체/재배면적 인출) 농식품부_AI에 보험 가입.

농식품부_AI: 감귤 농작물재해보험 가입 완료. 보험료 120만원 중 국비 50% 지원. 태풍/우박/동상해 보장.

4농업경영체 등록

농식품부_AI: 농업경영체 등록 완료(경영체번호: JJ-2026-12345). 직불금/정책자금/면세유 자격 확보됨.

사용자_AI: Vault '농업-경영체'에 기록. Hash → OpenHash L2 제주도 노드 저장.

사용자_AI: Vault '농업-시세정보'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.
