대화 예시

1한부모가족 지원 신청

사용자: 이혼해서 혼자 아이 키우는데 한부모가족 지원받을 수 있어?

사용자_AI: (Vault 가족관계/소득정보 인출) 여가부_AI에 지원 신청.

여가부_AI: 한부모가족 지원 신청 완료. 아동양육비 월 20만원, 학용품비 연 9.3만원 지원 대상. 복지급여 연계 가능.

사용자_AI: Vault '복지-한부모'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

2아이돌봄 서비스 신청

사용자: 맞벌이인데 아이 돌봄 서비스 신청하고 싶어.

사용자_AI: (Vault 가구정보/소득정보 인출) 여가부_AI에 돌봄서비스 신청.

여가부_AI: 아이돌봄 서비스 신청 완료. 시간제 돌봄(시간당 12,460원), 정부지원 75%. 돌보미 매칭 3일 내 연락 예정.

사용자_AI: Vault '복지-아이돌봄'에 기록. Hash → OpenHash L1 제주시 노드 저장.

3가정폭력 피해 지원

사용자: 남편한테 맞았어. 도움받을 수 있을까?

사용자_AI: (긴급 모드) 여가부_AI에 피해지원 연결.

여가부_AI: 여성긴급전화 1366 연결됨. 긴급 피난처 안내 가능. 법률/의료/심리 상담 무료 지원. 신변보호 필요 시 경찰청_AI 연계.

사용자_AI: Hash → OpenHash L4 대한민국 노드 저장(보호).

4경력단절여성 취업지원

사용자: 육아 끝나고 다시 취업하고 싶은데 도움받을 수 있어?

사용자_AI: (Vault 경력/자격정보 인출) 여가부_AI에 취업지원 신청.

여가부_AI: 여성새로일하기센터 등록 완료. 직업상담/직업훈련/취업연계 서비스 제공. 인턴십 프로그램(월 180만원) 참여 가능.

사용자_AI: Vault '취업-경단녀'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5청소년 쉼터 연계

사용자_AI: Hash → OpenHash L2 제주시 노드 저장.
