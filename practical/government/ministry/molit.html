대화 예시

1청약 점수 조회

사용자: 내 청약 점수랑 자격 조회해줘.

사용자_AI: (Vault 주택청약/무주택기간 인출) 국토부_AI에 청약점수 조회.

국토부_AI: 청약 점수 조회 완료. 가점 48점(무주택 15년, 부양가족 3인, 청약통장 8년). 1순위 자격 충족. 제주 분양 예정 3건 안내됨.

사용자_AI: Vault '주택-청약'에 기록. Hash → OpenHash L1 제주시 노드 저장.

2전월세 신고

사용자: 이사했는데 전세계약 신고해줘.

사용자_AI: (Vault 임대차계약서 인출) 국토부_AI에 전월세 신고.

국토부_AI: 주택 임대차 신고 완료. 보증금 2억원, 계약기간 2026.2-2028.2. 확정일자 자동 부여됨.

사용자_AI: Vault '주택-임대차'에 기록. Hash → OpenHash L1 제주시 노드 저장.

3건축 인허가 신청

사용자: 단독주택 신축하려는데 건축허가 신청해줘.

사용자_AI: (Vault 토지/설계도서 인출) 국토부_AI에 건축허가 신청.

국토부_AI: 건축허가 신청 접수 완료. 대지면적 300㎡, 연면적 150㎡. 심사기간 약 21일. 관련부서 협의 진행 예정.

사용자_AI: Vault '부동산-건축허가'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

4자동차 등록

사용자: 새 차 샀는데 등록해줘.

사용자_AI: (Vault 매매계약서/보험가입증 인출) 국토부_AI에 자동차 등록.

국토부_AI: 자동차 신규등록 완료. 취득세 자동 계산(면세 대상 아님). 등록번호: 제주12가3456. 등록증 배송 예정.

사용자_AI: Vault '자동차-등록'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5실거래가 조회

사용자: 이 아파트 최근 실거래가 알려줘.

사용자_AI: (아파트 주소 입력) 국토부_AI에 실거래가 조회.

국토부_AI: 제주시 연동 ○○아파트 84㎡ 실거래가: 최근 6개월 평균 4.2억원, 최고 4.5억(12월), 최저 3.9억(9월). 시세 추이 그래프 제공됨.

사용자_AI: Vault '부동산-시세조회'에 기록. Hash → OpenHash L1 제주시 노드 저장.
