대화 예시

1내과 진료 예약

사용자: 감기 걸린 것 같아. 집 근처 내과 예약해줘.

사용자_AI: (Vault 위치정보/건강보험증 인출) 전문의원_AI에 예약 요청.

전문의원_AI: 서귀포○○내과 예약 완료. 오늘 오후 3:00, 대기순번 5번. 주소: 서귀포시 중앙로 123. 증상 메모: 발열, 기침.

사용자_AI: Vault '의료-진료예약'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

2처방전 전송

사용자: 진료 끝났어. 처방전 집 근처 약국으로 보내줘.

사용자_AI: (Vault 위치정보/선호약국 인출) 전문의원_AI에 처방전 전송 요청.

전문의원_AI: 전자처방전 발급/전송 완료. 수신약국: 서귀포○○약국, 처방내용: 감기약 3일분. 약국_AI에 조제 예약됨. 15분 후 수령 가능.

사용자_AI: Vault '의료-처방전'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

3진단서 발급

사용자: 회사 제출용 진단서 발급해줘.

사용자_AI: (Vault 진료기록/용도 인출) 전문의원_AI에 진단서 발급 요청.

전문의원_AI: 진단서 발급 완료. 병명: 급성 상기도감염, 치료기간: 3일, 용도: 직장제출용. 발급비용 10,000원 결제됨. PDF 다운로드 가능.

사용자_AI: Vault '의료-진단서'에 저장. Hash → OpenHash L1 서귀포시 노드 저장.

4예방접종 예약

사용자: 독감 예방접종 맞으려고. 예약해줘.

사용자_AI: (Vault 예방접종이력/건강정보 인출) 전문의원_AI에 접종 예약.

전문의원_AI: 독감 예방접종 예약 완료. 일시: 내일 오전 9:30, 장소: 제주○○의원. 백신: 4가 독감백신. 비용: 무료(국가지원 대상).

사용자_AI: Vault '의료-예방접종'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5종합병원 전원 의뢰

사용자: 정밀검사가 필요하대. 큰 병원으로 의뢰서 써줘.

사용자_AI: (Vault 진료기록/희망병원 인출) 전문의원_AI에 전원 의뢰서 요청.

전문의원_AI: 진료의뢰서 발급 완료. 의뢰병원: 제주대병원 소화기내과, 의뢰사유: 상복부 통증 정밀검사. 종합병원_AI에 예약 연계됨.

사용자_AI: Vault '의료-진료의뢰'에 기록. Hash → OpenHash L2 제주시 노드 저장.
