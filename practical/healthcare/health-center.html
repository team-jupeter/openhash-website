대화 예시

1무료 건강검진 예약

사용자: 올해 무료 건강검진 대상인 것 같아. 예약해줘.

사용자_AI: (Vault 건강보험정보/생년월일 인출) 보건소_AI에 검진 예약 요청.

보건소_AI: 국가건강검진 대상자 확인. 서귀포시보건소 예약 완료. 일시: 2/8 오전 9:00. 검진항목: 일반검진+암검진(위암,대장암). 금식 필요.

사용자_AI: Vault '건강-국가검진'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

2무료 예방접종 예약

사용자: 아이 무료 예방접종 맞추려고. 예약해줘.

사용자_AI: (Vault 자녀정보/접종이력 인출) 보건소_AI에 접종 예약.

보건소_AI: 영유아 국가예방접종 예약 완료. 대상: 김○○(만 2세), 접종: DTaP 4차. 일시: 2/6 오후 2:00, 장소: 제주시보건소. 예진표 작성 필요.

사용자_AI: Vault '건강-예방접종'에 기록. Hash → OpenHash L1 제주시 노드 저장.

3금연클리닉 등록

사용자: 담배 끊고 싶어. 금연클리닉 등록해줘.

사용자_AI: (Vault 건강정보/흡연이력 인출) 보건소_AI에 금연클리닉 등록.

보건소_AI: 금연클리닉 등록 완료. 6개월 프로그램 시작. 초진 상담: 2/3 오전 10:00. 니코틴 패치/껌 무료 제공. 성공 시 인센티브 10만원.

사용자_AI: Vault '건강-금연'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

4정신건강 상담 예약

사용자: 요즘 우울해. 상담받고 싶어.

사용자_AI: (Vault 개인정보 인출) 보건소_AI에 상담 예약.

보건소_AI: 정신건강복지센터 상담 예약 완료. 일시: 2/4 오후 3:00, 방식: 대면상담, 담당: 전문상담사. 무료. 비밀보장됨.

사용자_AI: Vault '건강-정신상담'에 기록(보호). Hash → OpenHash L2 서귀포시 노드 저장.

5영유아 발달검사 예약

사용자: 아이 발달검사 시기 됐대. 예약해줘.

사용자_AI: (Vault 자녀정보/검진이력 인출) 보건소_AI에 발달검사 예약.

보건소_AI: 영유아 건강검진(발달평가) 예약 완료. 대상: 김○○(만 30개월), 검사: K-DST 발달선별검사. 일시: 2/10 오전 11:00. 검진표 사전작성 필요.

사용자_AI: Vault '건강-영유아검진'에 기록. Hash → OpenHash L1 제주시 노드 저장.
