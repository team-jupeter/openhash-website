대화 예시

1진료 예약

사용자: 서울대병원 정형외과 예약 잡아줘. 무릎이 아파.

사용자_AI: (Vault 건강보험증/진료기록 인출) 종합병원_AI에 예약 요청.

종합병원_AI: 서울대병원 정형외과 예약 완료. 일시: 2/5 오전 10:30, 담당: 김○○ 교수, 장소: 본관 3층 정형외과. 예약번호 SNU-2026-12345.

사용자_AI: Vault '의료-진료예약'에 기록. Hash → OpenHash L1 서울시 노드 저장.

2입원 수속

사용자: 수술 날짜 잡혔어. 입원 수속해줘.

사용자_AI: (Vault 수술예정서/보험정보/비상연락처 인출) 종합병원_AI에 입원 수속.

종합병원_AI: 입원 수속 완료. 입원일: 2/10, 병실: 81병동 4인실, 예상 입원기간 5일. 입원동의서/수술동의서 서명 필요. 선납금 100만원 결제됨.

사용자_AI: Vault '의료-입원'에 기록. Hash → OpenHash L2 서울시 노드 저장.

3수술 동의서 작성

사용자: 수술 동의서 내용 확인하고 서명해줘.

사용자_AI: (Vault 수술설명서 검토) 종합병원_AI에 동의서 확인 요청.

종합병원_AI: 수술동의서 표시: 수술명(십자인대재건술), 예상시간(2시간), 마취방법(전신마취), 합병증 위험(감염 1%, 재파열 3%). 서명 진행할까요?

(사용자 서명 승인)

사용자_AI: 전자서명 완료. Vault '의료-수술동의'에 저장. Hash → OpenHash L2 서울시 노드 저장.

4의무기록 발급

사용자: 보험 청구용으로 의무기록 사본 발급해줘.

사용자_AI: (Vault 본인인증/보험정보 인출) 종합병원_AI에 의무기록 발급 요청.

종합병원_AI: 의무기록 사본 발급 완료. 내용: 입퇴원기록, 수술기록, 진단서. 총 12페이지. 발급비용 12,000원. 보험_AI로 자동 전송됨.

사용자_AI: Vault '의료-의무기록'에 저장. Hash → OpenHash L2 서울시 노드 저장.

5진료비 수납 및 실비 청구

사용자: 퇴원 수속하고 진료비 내고 실비도 청구해줘.

사용자_AI: (Vault 결제정보/보험증권 인출) 종합병원_AI에 퇴원 및 수납 요청.

종합병원_AI: 퇴원 수속 완료. 총 진료비 320만원, 본인부담 85만원 결제됨. 진료비 영수증/세부내역서 발급. 보험_AI 연계 실비청구 자동 진행.

사용자_AI: Vault '의료-퇴원정산'에 기록. Hash → OpenHash L2 서울시 노드 저장.
