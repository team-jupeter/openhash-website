5단계 계층 구조

글로벌-국가-광역시도-시군구-읍면동 기반 데이터 무결성 검증

개요

OpenHash는 기존 통신 인프라의 물리적 계층 구조를 활용하여 데이터 무결성을 검증합니다. 5단계 행정 계층 구조(글로벌-국가-광역시도-시군구-읍면동)를 기반으로 모든 사용자와 거래가 관리됩니다.

핵심 원리: 네트워크를 단순한 데이터 전송 수단이 아닌 신뢰 인프라로 재해석합니다.

계층 구조

L5

글로벌 계층 (GLOBAL)

전 세계 최상위 검증 노드. 국가 간 거래의 최종 검증을 담당합니다.

  • 기록 확률: 일반 2% / 고중요도 10%
  • Representative 노드 1개
L4

국가 계층 (KR, US, JP...)

국가 단위 검증 및 규제 준수. AML/CFT 규정을 적용합니다.

  • 기록 확률: 일반 6% / 고중요도 25%
  • Representative 노드 1개 + 일반 노드 2~5개
L3

광역시도 계층 (KR-SEOUL, KR-JEJU...)

광역 단위 데이터 집계 및 이상 패턴 모니터링.

  • 기록 확률: 일반 12% / 고중요도 30%
  • Representative 노드 1개 + 일반 노드 3~7개
L2

시군구 계층 (KR-JEJU-SEOGWIPO...)

기초자치단체 단위 거래 처리 및 1차 검증.

  • 기록 확률: 일반 30% / 고중요도 20%
  • Representative 노드 1개 + 일반 노드 5~10개
L1

읍면동 계층 (KR-JEJU-SEOGWIPO-JUNGMUN...)

최하위 계층. 실시간 거래 처리의 최전선을 담당합니다.

  • 기록 확률: 일반 50% / 고중요도 15%
  • Representative 노드 1개 + 일반 노드 7~15개

Representative 노드

각 계층에는 대표 검증 노드(Representative Node)가 존재합니다.

선정 기준
