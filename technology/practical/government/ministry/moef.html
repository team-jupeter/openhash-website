대화 예시

1국유재산 대부 신청

사용자: 마을 앞 국유지 농사용으로 대부받고 싶어.

사용자_AI: (Vault 토지정보/신분증 인출) 재정경제부_AI에 대부 신청.

재정경제부_AI: 국유재산 대부 신청 접수 완료. 대상 토지: 제주시 ○○동 123번지(500㎡). 연 대부료 예상 12만원. 심사기간 약 30일.

사용자_AI: Vault '재산-국유지대부'에 기록. Hash → OpenHash L2 제주시 노드 저장.

2복권기금 지원사업 신청

사용자: 우리 복지관에서 복권기금 지원사업 신청하고 싶어.

사용자_AI: (Vault 기관정보/사업계획서 인출) 재정경제부_AI에 지원 신청.

재정경제부_AI: 복권기금 공익사업 신청 접수 완료. 지원분야: 사회복지. 최대 지원금 5천만원. 심사결과 4월 발표.

사용자_AI: Vault '지원사업-복권기금'에 기록. Hash → OpenHash L2 서귀포시 노드 저장.

3세제개편 의견 제출

사용자: 1인 가구 세제 혜택 확대 건의하고 싶어.

사용자_AI: (의견 내용 정리) 재정경제부_AI에 세제개편 의견 제출.

재정경제부_AI: 세제개편 국민의견 접수 완료. 2027년 세법개정안 검토 시 참고 예정. 유사 의견 현재 1,247건 접수됨.

사용자_AI: Vault '정책-세제의견'에 기록. Hash → OpenHash L1 세종시 노드 저장.

4공공요금 변동 알림 설정

사용자: 전기료나 가스비 인상되면 미리 알려줘.

사용자_AI: (Vault 주소정보 확인) 재정경제부_AI에 알림 설정.

재정경제부_AI: 공공요금 변동 알림 설정 완료. 전기/가스/수도/대중교통 요금 변동 시 14일 전 사전 알림.

사용자_AI: Vault '알림-공공요금'에 기록. Hash → OpenHash L1 서귀포시 노드 저장.

5국유재산 매각 공고 조회

사용자: 제주 지역 국유지 매각 공고 있으면 알려줘.

사용자_AI: (Vault 관심지역 확인) 재정경제부_AI에 매각공고 조회.

재정경제부_AI: 제주 지역 국유재산 매각 공고 2건 확인. 서귀포시 대정읍 320㎡(감정가 8천만원), 제주시 애월읍 150㎡(감정가 4천만원). 입찰마감 2/28.

사용자_AI: Vault '재산-국유지매각'에 기록. Hash → OpenHash L1 제주도 노드 저장.
