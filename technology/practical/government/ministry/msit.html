대화 예시

1국가R&D 과제 신청

사용자: AI 스타트업인데 정부 R&D 과제 신청하고 싶어.

사용자_AI: (Vault 기업정보/연구계획서 인출) 과기정통부_AI에 과제 신청.

과기정통부_AI: 'AI기반 혁신성장 지원사업' 신청 접수 완료. 지원규모 최대 5억원/3년. 서면평가 3월, 발표평가 4월 예정.

사용자_AI: Vault '연구-R&D과제'에 기록. Hash → OpenHash L3 대한민국 노드 저장.

2SW 인재양성 프로그램 신청

사용자: SW마에스트로 과정 지원하고 싶어.

사용자_AI: (Vault 학적/포트폴리오 인출) 과기정통부_AI에 프로그램 신청.

과기정통부_AI: SW마에스트로 16기 지원서 접수 완료. 1차 코딩테스트 3/5, 월 100만원 지원금 및 멘토링 제공.

사용자_AI: Vault '교육-SW마에스트로'에 기록. Hash → OpenHash L2 서울시 노드 저장.

3출연연 채용정보 조회

사용자: KAIST나 ETRI 같은 출연연 채용공고 있어?

사용자_AI: (Vault 경력/전공정보 확인) 과기정통부_AI에 채용정보 조회.

과기정통부_AI: 전공 매칭 채용공고 7건: ETRI AI연구실(2명), KIST 로봇센터(1명), KAIST 박사후연구원(4명). 지원서 자동작성 가능.

사용자_AI: Vault '취업-출연연'에 기록. Hash → OpenHash L1 대전시 노드 저장.

4정보통신 기술자격 신청

사용자: 정보처리기사 시험 접수해줘.

사용자_AI: (Vault 신분정보/학력 인출) 과기정통부_AI에 자격검정 신청.

과기정통부_AI: 정보처리기사 필기시험 접수 완료. 시험일: 3/15, 장소: 제주대학교. 수험료 19,400원 결제됨.

사용자_AI: Vault '자격-정보처리기사'에 기록. Hash → OpenHash L1 제주시 노드 저장.

5K-PASS 기술등급 확인

사용자: 내 과학기술인 등급 확인하고 경력증명서 발급해줘.

사용자_AI: (Vault 연구경력 인출) 과기정통부_AI에 등급 조회.

과기정통부_AI: K-PASS 등록 확인. 기술등급: 특급기술자. 경력 12년 3개월. 경력증명서 발급 완료.

사용자_AI: Vault '자격-기술등급'에 저장. Hash → OpenHash L2 서울시 노드 저장.
