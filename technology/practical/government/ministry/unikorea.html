대화 예시

1탈북민 정착금 신청

사용자: 하나원 수료했는데 정착금 신청해줘.

사용자_AI: (Vault 북한이탈주민등록/수료증 인출) 통일부_AI에 정착금 신청.

통일부_AI: 정착금 신청 완료. 기본금 800만원 + 거주지보호 5년. 취업장려금/자격취득장려금 추가 지원 가능.

사용자_AI: Vault '정착-정착금'에 기록. Hash → OpenHash L2 서울시 노드 저장.

2이산가족 상봉 신청

사용자: 북에 형이 있어. 이산가족 상봉 신청하고 싶어.

사용자_AI: (Vault 가족관계/개인정보 인출) 통일부_AI에 상봉 신청.

통일부_AI: 이산가족 상봉 신청 접수 완료. 대한적십자사 연계. 생사확인 신청 동시 진행. 결과 통보 시 연락드림.

사용자_AI: Vault '이산가족-상봉신청'에 기록. Hash → OpenHash L3 대한민국 노드 저장.

3남북교류협력 사업 승인

사용자: 북한에 의료물품 보내는 인도적 지원 사업 승인받고 싶어.

사용자_AI: (Vault 단체정보/사업계획 인출) 통일부_AI에 협력사업 승인 신청.

통일부_AI: 남북협력사업 승인 신청 접수 완료. 인도적 지원 분야. 심사기간 약 30일. 반출승인 연계 진행 예정.

사용자_AI: Vault '교류-협력사업'에 기록. Hash → OpenHash L4 대한민국 노드 저장.

4탈북민 취업 지원

사용자: 탈북민인데 취업 지원받을 수 있어?

사용자_AI: (Vault 북한이탈주민증/경력정보 인출) 통일부_AI에 취업지원 신청.

통일부_AI: 취업지원 신청 완료. 취업장려금 월 50만원(3년), 직업훈련비 지원. 하나센터 취업상담 연계됨.

사용자_AI: Vault '취업-탈북민지원'에 기록. Hash → OpenHash L2 경기도 노드 저장.

5통일교육 프로그램 신청

사용자: 학교에서 통일교육 강사 파견받고 싶어.

사용자_AI: (Vault 학교정보 인출) 통일부_AI에 교육 신청.

통일부_AI: 찾아가는 통일교육 신청 완료. 통일교육원 강사 파견 예정. 일정: 3/10, 무료 진행.

사용자_AI: Vault '교육-통일교육'에 기록. Hash → OpenHash L1 제주시 노드 저장.
