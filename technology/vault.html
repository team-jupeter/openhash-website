Vault 서비스

금융/의료/교육/행정/교통/일반 6서랍 자동 분류 데이터 관리

개요

Vault는 사용자의 개인 데이터를 6개의 카테고리(서랍)로 자동 분류하여 안전하게 저장하는 개인 데이터 금고 서비스입니다. AI 기반 분류 시스템이 데이터 유형을 자동으로 판별합니다.

6개 서랍 구조

서랍아이콘저장 데이터예시
FINANCE💰금융 정보거래 내역, 계좌, 세금
MEDICAL🏥의료 정보진료 기록, 처방전, 건강검진
EDUCATION🎓교육 정보학력, 자격증, 수료증
ADMIN📋행정 정보주민등록, 운전면허, 여권
TRANSPORT🚗교통 정보차량등록, 교통카드, 주차
GENERAL📁일반 정보기타 분류되지 않은 데이터

AI 자동 분류

데이터 저장 시 AI가 내용을 분석하여 적절한 서랍을 추천합니다.

// 분류 알고리즘 function classifyData(content) { // 1. 텍스트 특징 추출 features = extractFeatures(content); // 2. 분류 모델 추론 predictions = classificationModel.predict(features); // 3. 가장 높은 확률의 서랍 반환 return { drawer: argmax(predictions), confidence: max(predictions) }; }

선택적 공유

사용자는 필요한 데이터만 선택하여 제3자에게 공유할 수 있습니다.

  • 시간 제한 공유 (1회성, 기간 한정)
  • 부분 공개 (마스킹 처리)
  • 검증만 허용 (원본 미제공)
